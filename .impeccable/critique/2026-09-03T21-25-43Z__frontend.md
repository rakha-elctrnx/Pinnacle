### Design Specificity Verdict

**Verified assessment**: Foundation is strong — comprehensive token system (frontend/index.css: light+dark, full type scale, focus/danger/success rings), real keyboard support, validator, staged-edit model with undo/redo. Main authenticity gap vs the stated spec (TablePlus/Raycast, dark-first): a second, hardcoded light-only styling system lives across several features, breaking dark mode there.

**Deterministic scan**: 4 gray-on-color warnings; 3 false positives (hover-state pairs), 1 minor real (IndexManager.tsx:411 slate-700 on blue-50/40 hover tint). Browser overlay: flat type hierarchy (11→20px, ratio 1.8), transition:width on both asides, caption line-height 1.27x.

### Priority Issues

- **[P1] Hardcoded light-only classes break dark mode** — frontend/features/elasticsearch/components/ (ClusterDashboard.tsx, IndexManager.tsx, MappingExplorer.tsx), \_shared ConnectionHeader.tsx, DetailsPanel.tsx, CenteredLoadingState.tsx:94-95 (bg-white), ui/Combobox.tsx:117-140, sql/components/table-designer/ (ColumnEditor, ForeignKeyEditor, IndexEditor, PrimaryKeyEditor), export/DataOperationModal.tsx. All use bg-white/slate-_/blue-_ which ignore data-theme.
  - Fix: migrate to tokens (bg-bg-base, text-text-primary, border-border-default); lint rule to ban raw slate/blue/white utilities outside code-preview blocks.
- **[P1] Dark mode is not the default despite "dark mode first" spec** — frontend/app/theme.tsx:20 defaults to 'light'.
  - Fix: default 'dark', respect OS prefers-color-scheme.
- **[P2] Brand color deviation** — index.css:17 uses #3b60cd; copilot-instructions spec says #009ddc. Note: #009ddc on white = 3.06:1 (fails AA for text); current #3b60cd = 5.61:1. Decide: update spec to #3b60cd, or keep spec color for accents only.
- **[P2] No query cancellation** — no AbortController/cancel in frontend/services/; long-running queries cannot be stopped (status shows spinner only).
- **[P2] Light muted text 4.44:1** — index.css:14 #737370 on #f6f7f9, just under AA 4.5:1.
- **[P3] Width transition on both asides** — DataExplorerLayout.tsx:565,595 transition-[width] 300ms causes layout thrash on collapse; use transform or content-visibility.
- **[P3] Caption line-height 1.27x** — index.css:79-80 (14px/11px); raise to >=1.3.
